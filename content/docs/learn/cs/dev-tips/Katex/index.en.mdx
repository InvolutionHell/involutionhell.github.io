KaTeX differs slightly from LaTeX in certain ways — here is a quick reference for personal use.

Wrap instructions between two `$` symbols to enable inline math mode, which renders alongside normal text without interruption.

Wrap instructions between two `$$` symbols to display a formula as a standalone centered block.
